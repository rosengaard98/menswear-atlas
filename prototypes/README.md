# Design prototypes

Three variations of the free-floating web (Glass, Gallery, Orrery), built by `node prototypes/make.mjs` from the built site data (`npm run build` first). Open the generated `*.html` files in a browser.

The four photographs in `img/` are CC0 images from the Cleveland Museum of Art open-access collection, used here as stand-ins for the hover backgrounds: portrait miniature c. 1780s (2010.5), portrait of a man (2011.46), Portrait of a Gentleman 1887 (2016.266.1), Polo Sketch 1921 (1936.640).
